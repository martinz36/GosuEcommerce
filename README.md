# GOSU® E-Commerce Engine

Premium TCG Accessories & Collector Gear E-Commerce Platform. Built from scratch with Next.js App Router, Tailwind CSS, Framer Motion, Neon PostgreSQL (Prisma ORM), Cloudinary, and Stripe Payments.

## 🚀 Features

- **Storefront Design System**: Custom brutalist/neon high-contrast design system extracted from Framer with responsive animations (`framer-motion`).
- **Postgres Database (Neon + Prisma ORM)**:
  - Multi-role User Management (`CUSTOMER`, `AFFILIATE`, `ADMIN`) & Referral Tree.
  - Product & Variant Catalog with Cloudinary image management.
  - Bundles / Packs with dynamic discount grouping.
  - Comprehensive Discount Engine (`PROMO`, `REFERRAL`, `AFFILIATE` codes with commission tracking).
  - Orders & Stripe PaymentIntent workflow.

## 🛠️ Stack

- **Framework**: Next.js 14 (App Router, TypeScript)
- **Styling**: Tailwind CSS & Framer Motion
- **Database**: Neon (Serverless Postgres) + Prisma ORM
- **Images**: Cloudinary
- **Payments**: Stripe
